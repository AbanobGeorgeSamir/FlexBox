# FlexBox Layout

A small CSS Flexbox practice project: a page with a header and navigation built with HTML5 and CSS3 Flexbox, over a full-size background image.

**[Live site](https://flex-box-five-pi.vercel.app)**

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)
![Vercel](https://img.shields.io/badge/Vercel-000000?style=flat-square&logo=vercel&logoColor=white)

## What it covers

- Flexbox for the header, navigation and content alignment
- Semantic HTML5 structure
- Plain CSS with a background image, with no frameworks

## Getting Started

No build step is needed. Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/AbanobGeorgeSamir/FlexBox.git
cd FlexBox
```

## Project Structure

```text
index.html   Page markup
style.css    Styles
images/      Background image
```
