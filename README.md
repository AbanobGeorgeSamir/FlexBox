# 📐 FlexBox Layout

A CSS Flexbox demonstration project — responsive, semantic HTML with modern visual design and mobile-first styling.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)

## ✨ Features

- 📱 Fully responsive Flexbox layout
- 🧱 Semantic HTML5 structure
- 🎨 Clean visual design with background imagery
- 📐 Demonstrates core Flexbox patterns: wrap, alignment, spacing

## 🚀 Getting Started

```bash
git clone https://github.com/AbanobGeorgeSamir/FlexBox.git
cd FlexBox
# Open index.html in your browser
```

## 📚 Flexbox Patterns Demonstrated

| Pattern | CSS Property |
|---|---|
| Row / Column layout | `flex-direction` |
| Wrapping | `flex-wrap` |
| Alignment | `align-items`, `justify-content` |
| Item sizing | `flex-grow`, `flex-shrink`, `flex-basis` |
